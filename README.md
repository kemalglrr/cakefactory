# Cake Factory Bakırköy — Tanıtım Sitesi & QR Menü

Bir pastane için hazırlanmış tek sayfalık tanıtım sitesi ve fotoğraflı, mobil öncelikli QR menü.

## Özellikler

- Ürün görselleriyle interaktif menü sayfası (`/menu`) — masalardaki QR kod bu sayfaya yönlendirir
- Toptan satış bölümü
- Tamamen responsive, mobil öncelikli tasarım

## Teknolojiler

- **Next.js 14** (App Router)
- **React 18**
- Vercel üzerinde deploy

## Kurulum

```bash
npm install
npm run dev
```

`http://localhost:3000` — ana sayfa, `http://localhost:3000/menu` — QR menü.
